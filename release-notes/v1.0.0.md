## 家庭服务器管理中心 v1.0.0

首个公开发布版本。以 Docker 镜像形式分发，本 Release 提供部署所需的编排文件与环境变量模板。

### 镜像

| 镜像 | 架构 | 摘要（latest） |
| --- | --- | --- |
| `docker.io/vanjayak/server-management-backend:latest` | linux/amd64, linux/arm64 | `sha256:f1170b0b0d48d6fad5c775840181d3cd1859902ddb5afe0afc99e935849d6049` |
| `docker.io/vanjayak/server-management-frontend:latest` | linux/amd64, linux/arm64 | `sha256:bcfd2c4cfe481fb7c394fd023652b3bb0e23216123d145561dd50d98488768dc` |

需要固定版本时，可在 `.env` 中写入 `BACKEND_IMAGE=docker.io/vanjayak/server-management-backend@sha256:...` 与 `FRONTEND_IMAGE=...@sha256:...`。

### 部署

```bash
mkdir home-server-manager && cd home-server-manager
curl -LO https://github.com/wangwanjie/my_web_page/releases/latest/download/docker-compose.yml
curl -L -o .env https://github.com/wangwanjie/my_web_page/releases/latest/download/env.example
for k in JWT_SECRET JWT_REFRESH_SECRET OAUTH_STATE_SECRET; do
  sed -i "s|^$k=.*|$k=$(openssl rand -hex 32)|" .env
done
docker compose up -d
```

访问 `http://主机IP:3800`。**首次登录的默认账号为 `admin / ChangeMe123!`，请立即在「设置 → 管理员设置」修改。** 需要远程开机时，按 `docker-compose.yml` 中的注释改用 host 网络。

### 功能

- 网络唤醒远程开机，SSH 关机与重启（私钥或密码认证，可测试连接）
- 定时关机与重启：写入目标服务器的 crontab，可查看、编辑、停用、删除
- 服务入口导航：分组、四种访问地址、未登录可见控制
- TOTP 双因素认证，可选 Google / GitHub / QQ 第三方登录
